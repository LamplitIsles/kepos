# 02 — Subscriber documentation journey

**What to build:** Publish a real public documentation route that explains publisher and subscriber, then guides an Android, macOS, or Windows subscriber from a verified download through pairing and opening or copying its first local service address.

**Blocked by:** 01 — Three-platform landing experience.

Status: completed

- [x] The public docs route is built, indexed in the sitemap, linked from the landing page, and deployable through the existing Cloudflare static-assets workflow.
- [x] The page begins with an action-oriented publisher/subscriber explanation and exposes distinct setup entrances for sharing and connecting.
- [x] Subscriber instructions cover the supported Android, macOS, and Windows release boundaries, expected installation warnings, identity ownership, pairing, connection states, and first-service outcome.
- [x] Latest-stable behavior, SHA-256/Minisign verification, unsigned or ad-hoc-signed preview boundaries, and secret-state handling are explained without making verification tooling a prerequisite to understand setup.
- [x] Local anchors, labels, external-link safety, responsive wrapping, focus order, icon registration, reduced motion, and built-route output pass the website's behavioral checks and browser review.
