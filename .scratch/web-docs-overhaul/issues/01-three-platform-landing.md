# 01 — Three-platform landing experience

**What to build:** Make the public landing page present Android, macOS, and Windows as first-class downloads, with accurate role support, device-oriented Lucide icons, and a non-blocking recommendation for the visitor's detected platform.

**Blocked by:** None — can start immediately.

Status: completed

- [x] Android, macOS, and Windows downloads are always visible, accessible, and use versionless latest-stable artifact URLs.
- [x] Android is identified as subscriber-only while macOS and Windows are identified as publisher/subscriber capable.
- [x] Android, macOS, Windows, and unknown browser environments produce the intended emphasis without hiding or redirecting any choice.
- [x] The landing page exposes a working Docs entry and remains responsive and keyboard accessible at desktop and mobile widths.
- [x] Website behavioral tests cover the stable download and recommendation contracts without asserting editorial wording.
