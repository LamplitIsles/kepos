GET STARTED · LINUX

Connect two peers.

The Linux VPN is an experimental foundation for people comfortable configuring their own machines.

Before you begin

Each peer needs Linux, Node.js 24, a C compiler and kernel headers, ip from iproute2, access to /dev/net/tun, and permission to configure its network interface and routes. HyperDHT discovery and transport require UDP reachability on the physical network.

Configure the VPN

Create an identity on each peer, exchange public keys, and configure distinct VPN addresses and inbound TCP port grants. The guide covers building the TUN helper, configuration, startup, and current limitations.

Read the VPN guide →

Use your existing domains

Point your DNS record at the destination peer's VPN address. Your HTTPS server must listen on that address and present a certificate for the hostname.

Only IPv4 TCP between configured peers is supported today. There is no subnet routing, exit node, application UDP, or IPv6 overlay; no iOS or macOS VPN client is supplied.
