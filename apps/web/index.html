01 / THE PRODUCT

Open services.
Copy local addresses.

Web services open in place. TCP services expose a local address.

02 / PRIVATE TOPOLOGY

One publisher.
Only trusted peers.

The publisher accepts public keys from its local allowlist.

03 / WHY KEPOS

Services,
not a subnet.

Mesh VPNs connect devices. Kepos exposes only selected services.

01 / SCOPE

Choose what to expose.

Publish a web app, TCP service, or shell—not the rest of the machine.

02 / TRUST

Keep access local.

The service owner controls a public-key allowlist. No hosted account can grant access.

03 / SPACE

No network to administer.

Subscribers get local addresses only for services they can use.

LIMITS

Kepos has no subnet routing or relay fallback. Use a mesh VPN when you need either.

04 / HOW IT WORKS

Direct, authenticated,
and service-scoped.

01

02

03

Open

One encrypted connection carries separate channels for the allowed services.
